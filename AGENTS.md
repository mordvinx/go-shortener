# Тестирование

- При добавлении и изменении поведения сервиса сразу добавляй или обновляй соответствующие тесты. Проверяй успешные, ошибочные и существенные граничные сценарии.
- Тесты должны проверять наблюдаемое поведение. Не пиши тесты на содержимое конфигурационных файлов и не дублируй конфигурацию ожидаемыми объектами; работу флагов и переменных окружения проверяй через поведение приложения.
- Перед сдачей инкремента запускай `go test ./...`, `go vet ./...` и проверяй покрытие через `go test -cover ./...`. Для общего покрытия с учётом вызовов между пакетами используй `go test -coverpkg=./... -coverprofile=/tmp/go-shortener.cover ./...` и `go tool cover -func=/tmp/go-shortener.cover`.
- Не забывай проверять, что автотесты текущего и предыдущих инкрементов проходят.
- Во введении в спринт 2 рекомендовано покрытие не менее 10% к концу спринта. В первой половине курса целевой процент рекомендательный, во второй станет обязательным. Для следующих спринтов сверяйся с их условиями; не увеличивай процент бессодержательными тестами.
